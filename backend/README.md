# NEXO RJ — Backend

- Instalação, dados e execução: [README principal](../README.md#como-executar).
- Documentação técnica completa (cada etapa, variáveis de configuração, API e avaliações): [docs/README_TECNICO.md](docs/README_TECNICO.md).
- Arquitetura, decisões e limitações: [ARQUITETURA.md](ARQUITETURA.md).

Os comandos de instalação, testes e da API rodam **dentro desta pasta** (`cd backend`).
